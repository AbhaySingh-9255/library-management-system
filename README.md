# 📚 Nexus Library Management System

A modern, eye-friendly Flask-based library management system , book cover previews, and issue/return tracking.

## ✨ Features
- **Modern UI:** Glassmorphism design with soft slate colors for reduced eye strain.
- **AI Search:** Natural language query support (e.g., "Show overdue books").
- **Book Covers:** Auto-generated placeholders or custom image URLs.
- **Issue/Return System:** Track due dates, calculate fines automatically.
- **Filtering:** View All, Available, Issued, Overdue books.
- **Responsive Design:** Works on desktop and mobile.

## 🛠️ Tech Stack
- **Backend:** Python, Flask, SQLAlchemy
- **Frontend:** HTML5, CSS3, JavaScript
- **Database:** SQLite (local) / PostgreSQL (online via Neon/Supabase)
- **Deployment:** Gunicorn + Render/Railway
